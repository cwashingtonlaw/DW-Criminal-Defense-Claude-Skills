# Louisiana Citation Style

Standard citation conventions used in all D&W Louisiana state pleadings. Hybrid Louisiana / Bluebook for federal pleadings citing Louisiana cases.

## Constitutional citations

- **Louisiana Constitution:** `La. Const. art. I, § 5`
- **U.S. Constitution:** `U.S. Const. amend. IV`

## Code citations

- **Code of Criminal Procedure:** `La. C.Cr.P. art. 703`
- **Code of Evidence:** `La. C.E. art. 702`
- **Civil Code:** `La. C.C. art. ___` (rare in criminal practice)
- **Code of Civil Procedure:** `La. C.C.P. art. ___` (rare in criminal practice)
- **Children's Code:** `La. Ch.C. art. 412`

## Statute citations

- **Revised Statutes:** `La. R.S. 14:30` (Title:Section format, no comma)
- **Multiple sections:** `La. R.S. 14:30, 14:30.1`
- **Subsections:** `La. R.S. 15:529.1(A)(1)(b)(ii)`

## Case citations — Louisiana

**Modern (post-1994 So. 3d format):**
```
State v. Henderson, 2020-01016 (La. 6/3/22), 359 So. 3d 1 [pin cite]
```

**Older (Southern 2d):**
```
State v. Brown, 480 So. 2d 372 (La. App. 5 Cir. 1985)
```

**Court of Appeal — first cite:**
```
State v. Smith, 2018-0123 (La. App. 4 Cir. 5/15/19), 271 So. 3d 234
```

**Subsequent cite (short form):**
```
Smith, 271 So. 3d at 237.
```

**Pin cites:** always include `at ___` for pin cites in subsequent references.

## Case citations — federal

**U.S. Supreme Court:**
```
Carpenter v. United States, 138 S. Ct. 2206 (2018)
Miranda v. Arizona, 384 U.S. 436, 478-79 (1966)
```

**5th Circuit:**
```
United States v. Smith, 919 F.3d 825 (5th Cir. 2019)
```

**District court:**
```
United States v. Doe, No. 19-cr-12345, 2020 WL 1234567 (W.D. La. Mar. 15, 2020)
```

## Frequently used Louisiana criminal cases (short forms)

- **State v. Prieur, 277 So. 2d 126 (La. 1973)** — 404(b) procedure
- **State v. Foret, 628 So. 2d 1116 (La. 1993)** — Louisiana Daubert
- **State v. Hampton, 1998-0331 (La. 4/23/99), 750 So. 2d 867** — bond/excessive bail
- **State v. Dorthey, 623 So. 2d 1276 (La. 1993)** — excessive sentence challenge
- **State v. Henderson, 2020-01016 (La. 6/3/22), 359 So. 3d 1** — eyewitness ID
- **State v. Brady, 414 U.S. 5 (1973)** — wait, this is U.S. Supreme Court — Brady v. Maryland is `373 U.S. 83 (1963)`. Use full federal citation form for Brady.

When in doubt about a frequently-cited case, verify the cite via WestLaw or the Louisiana Supreme Court website before filing — citation errors undermine credibility.

## Signal usage

- `See` — supports proposition by inference
- `See, e.g.,` — supports with example
- `Cf.` — analogous but distinct
- `But see` — contradicts proposition
- `Compare ___ with ___` — compares two authorities
- No signal — directly supports proposition

## Formatting

- Italicize case names: `State v. Henderson`
- Italicize Latin abbreviations: `e.g.`, `i.e.`, `id.`
- Do NOT italicize statutory abbreviations (`La. R.S.`, `La. C.Cr.P.`)
- Pinpoint cites use `at`: `Henderson, 359 So. 3d at 12`
- Subsequent same-source cite: `Id.` (italicized) — used only when no other authority intervenes
- Subsequent different-page cite: `Id. at 14`

## Federal pleadings citing Louisiana cases

In federal pleadings, follow Bluebook for federal authority and use Louisiana Supreme Court / state court conventions for Louisiana cases as shown above. WDLA judges expect clean Bluebook for federal cites.
