# Companion Skill Routing Matrix

## Quick Reference — Companion Skill Integration

| When You Find... | Hand Off To... | Trigger Description |
|-----------------|---------------|-------------------|
| Cell tower, GPS, geofence, Wi-Fi location | **dw-cell-site-geolocation-auditor** | Location-based evidence requiring spatial analysis |
| Extraction issues, parsing artifacts, locked containers | **dw-mobile-forensic-auditor** | Methodology and extraction integrity questions |
| Cross-exam ammunition | **dw-cross-exam-architect** | Findings requiring witness preparation |
| Brady/Giglio material, selective extraction | **dw-brady-giglio-auditor** | Disclosure and withheld evidence issues |
| Social media auth challenges | **dw-social-media-auditor** | Social media evidence authentication |
| Suppression motion evidence (4th/5th) | **dw-suppression-motion** | Constitutional search/seizure or privilege claims |
| SQLite/WAL deleted data recovery | **dw-sqlite-recovery** | Deleted data recovery from database files |
| Body cam, dash cam, surveillance video (not phone-recorded) | **dw-video-evidence-auditor** | Non-phone video evidence analysis |
