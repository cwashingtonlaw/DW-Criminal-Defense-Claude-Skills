# Module H — Investigation Progress Tracker

Track all investigation tasks from assignment through completion.

## Progress Tracker Format

```
INVESTIGATION PROGRESS REPORT

Case: State v. [Defendant]          Case No.: [Number]
Report Date: [Date]
Reporting Period: [Start Date] to [End Date]
Lead Investigator: [Name]

SUMMARY:
- Total Tasks Assigned: [Number]
- Tasks Completed: [Number] ([Percentage]%)
- Tasks In Progress: [Number]
- Tasks Not Started: [Number]
- Tasks Blocked: [Number]
- New Tasks Added This Period: [Number]

CRITICAL/OVERDUE TASKS:
| Task ID | Description | Assigned To | Deadline | Status | Blocker |
|---------|-------------|-------------|----------|--------|---------|
|         |             |             |          |        |         |

COMPLETED TASKS THIS PERIOD:
| Task ID | Description | Completed Date | Result Summary | Impact on Defense |
|---------|-------------|----------------|----------------|-------------------|
|         |             |                |                |                   |

TASKS IN PROGRESS:
| Task ID | Description | Assigned To | Expected Completion | % Complete | Notes |
|---------|-------------|-------------|---------------------|------------|-------|
|         |             |             |                     |            |       |

NEW INFORMATION / LEAD CHANGES:
[Narrative description of new information received and how it affects investigation priorities]

RECOMMENDED PRIORITY CHANGES:
[Any tasks that should be elevated or deprioritized based on new information]

BUDGET STATUS:
- Authorized Budget: $[Amount]
- Spent to Date: $[Amount]
- Remaining: $[Amount]
- Projected Total: $[Amount]
- Variance: [Over/Under by $Amount]

NEXT PERIOD PRIORITIES:
1. [Priority task for next period]
2. [Priority task]
3. [Priority task]
```
