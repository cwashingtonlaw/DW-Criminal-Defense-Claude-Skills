# Daniels & Washington — TextExpander Snippets Skill
**Version 1.0 | Internal Use Only**

This skill manages the firm's TextExpander snippet library — standardized text blocks for captions, signature blocks, statutory citations, and boilerplate legal language used across all case documents. When drafting any document, Cowork checks for applicable snippets before generating generic text.

---

## Core Rules

- **Snippets override generic drafting.** When a TextExpander snippet exists for a text block, use the snippet version — it reflects the firm's preferred language.
- **Part of the Template-First Drafting Rule.** After checking DEVONthink for templates (see `dw-devonthink` skill), check TextExpander for applicable snippets.
- **Snippet format:** Each snippet has an abbreviation trigger (e.g., `;caption`) and expansion text.
- **Attorney maintains the snippet library.** Cowork suggests new snippets; attorney approves additions.

### Certificate of Service
**Trigger:** `;cos`

```
CERTIFICATE OF SERVICE

I hereby certify that a copy of the foregoing has been served upon the
Calcasieu Parish District Attorney's Office by [hand delivery / electronic
filing / certified mail] on this ____ day of _____________, 20___.

____________________________________
[ATTORNEY NAME]
```

### Privileged Marking
**Trigger:** `;priv`

```
ATTORNEY-CLIENT COMMUNICATION — PRIVILEGED AND CONFIDENTIAL
This document is protected by the attorney-client privilege and/or the
work product doctrine. Unauthorized disclosure is prohibited.
```

### Work Product Marking
**Trigger:** `;wp`

```
ATTORNEY WORK PRODUCT — PRIVILEGED AND CONFIDENTIAL
Prepared in anticipation of litigation. Protected by the work product
doctrine. Not for disclosure.
```

```
405 U.S. 150 (1972), and Kyles v. Whitley, 514 U.S. 419 (1995),

```

### Miranda Warning Reference
**Trigger:** `;miranda`

```
Miranda v. Arizona, 384 U.S. 436 (1966); La. C.Cr.P. Art. 218.1
(Rights of persons arrested or detained); La. Const. Art. I, § 13
(Rights of the accused).
```

### Burden of Proof Statement
**Trigger:** `;burden`

```
The State bears the burden of proving every element of the charged
offense beyond a reasonable doubt. La. C.Cr.P. Art. 804; Jackson v.
Virginia, 443 U.S. 307 (1979). The defendant is presumed innocent,
and this presumption remains with the defendant throughout the trial.
La. C.Cr.P. Art. 804(B).
```

### Excessiveness Standard
**Trigger:** `;excess`

```
Louisiana Constitution Article I, § 20 prohibits cruel, excessive, or
unusual punishment. A sentence is constitutionally excessive if it is
grossly disproportionate to the severity of the offense or is nothing
more than a purposeless and needless imposition of pain and suffering.
State v. Dorthey, 623 So.2d 1276 (La. 1993); State v. Barling,
779 So.2d 1035 (La. App. 2001).
```

### Cowork Draft Disclaimer
**Trigger:** `;draft`

```
DRAFT — PREPARED BY CLAUDE COWORK FOR ATTORNEY REVIEW
This document was generated by Claude Cowork and has NOT been reviewed
or approved by an attorney. Attorney must review, verify all facts and
citations, and approve before filing or sending.
```

## How to Use Snippets in Drafting

When generating any document that includes standard text blocks:

1. **Check this skill** for applicable snippets
2. **Use the snippet text exactly** — do not paraphrase or modify the firm's standard language
3. **Fill in variables** (shown in `[BRACKETS]`) with case-specific data
4. **Note in the document** when a firm snippet was used, so the attorney knows the language is standardized

### Documents That Commonly Use Snippets

| Document Type | Snippets Used |
|--------------|---------------|
| Any motion | `;caption`, `;sig`, `;cos`, `;draft` |
| Discovery demand | `;caption`, `;disco`, `;sig`, `;cos` |
| Suppression motion | `;caption`, `;miranda`, `;sig`, `;cos` |
| Sentencing memo | `;caption`, `;excess`, `;burden`, `;sig` |
| Client letter | `;priv`, `;sig` (modified for correspondence) |
| Internal memo | `;wp`, `;draft` |

## Managing the Snippet Library

### Adding New Snippets
When the attorney identifies recurring language that should be standardized:
1. Draft the snippet text
2. Suggest a trigger abbreviation (`;prefix` format)
3. Present to attorney for approval
4. Add to this skill file once approved

### Snippet Maintenance
Periodically review snippets for:
- Updated statutory citations (legislative changes)
- Updated case law references
- Changes in firm contact information
- New document types requiring standard language
