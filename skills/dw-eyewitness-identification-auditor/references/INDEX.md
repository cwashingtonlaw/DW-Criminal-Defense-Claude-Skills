### Module C: System Variable Analysis
**File**: `module-c-system-variables.md` (2.7 KB)

- C.1: Comprehensive system variable checklist

### Module D: Estimator Variable Analysis
**File**: `module-d-estimator-variables.md` (8.6 KB)

- D.1: Perception conditions (lighting, distance, duration, stress, weapon focus)
- D.2: Witness factors (age, vision, intoxication, attention)
- D.3: Memory factors (retention phase, decay curves, interval effects)
- D.4: Estimator variable risk matrix

**Use when**: Evaluating viewing conditions, witness reliability, and memory decay

### Module E: Suggestiveness Assessment

- E.1: Suggestiveness sources (administrator knowledge, suspect standout, feedback)

- E.3: Repeated identification procedure contamination

**Use when**: Determining if procedure was "impermissibly suggestive"
