## MODULE C -- System Variable Analysis

System variables are factors under the control of law enforcement that affect the reliability of the identification. These are the factors the police can get right or get wrong. The Henderson court (State v. Henderson, 27 A.3d 872 (N.J. 2011)) organized eyewitness reliability analysis around system and estimator variables, and this framework has been influential nationally although not formally adopted in Louisiana.

### C.1 -- Comprehensive System Variable Checklist

For each identification procedure in the case, evaluate every system variable:

| System Variable | Best Practice | This Case | Finding |
|----------------|-------------|-----------|---------|
| **Blind administration** | Double-blind | [Assess] | [CRITICAL / COMPLIANT] |
| **Lineup composition** | Description-based fillers; functional size >= 4 | [Assess] | [CRITICAL / SIGNIFICANT / COMPLIANT] |
| **Lineup size** | Minimum six; more is better | [Assess] | [Per La. C.Cr.P. Art. 163] |
| **Filler similarity** | Match witness description; no suspect standout | [Assess] | [CRITICAL / SIGNIFICANT / COMPLIANT] |
| **Pre-identification instructions** | Unbiased instruction given and documented | [Assess] | [CRITICAL / COMPLIANT] |
| **Presentation method** | Sequential preferred (NAS) | [Assess] | [SIGNIFICANT / COMPLIANT] |
| **Confidence statement** | Immediate, pre-feedback, verbatim | [Assess] | [CRITICAL / SIGNIFICANT / COMPLIANT] |
| **Post-identification feedback** | None given before confidence recorded | [Assess] | [CRITICAL / COMPLIANT] |
| **Recording** | Video/audio of entire procedure | [Assess] | [SIGNIFICANT / COMPLIANT] |
| **Multiple procedures** | Avoided if possible; if necessary, different fillers used | [Assess] | [CRITICAL / SIGNIFICANT / COMPLIANT] |
| **Witness separation** | Witnesses kept apart; no co-witness discussion | [Assess] | [CRITICAL / COMPLIANT] |
| **Administrator comments** | Neutral throughout; no evaluative statements | [Assess] | [CRITICAL / COMPLIANT] |

### C.2 -- Cumulative System Variable Deficiency Score

No single system variable deficiency exists in isolation. Multiple deficiencies compound unreliability:

- **0 deficiencies:** Procedure complied with best practices. Note compliance -- credibility requires intellectual honesty.
- **1-2 SIGNIFICANT deficiencies:** Procedure had notable shortcomings. Weight argument; cross-examination material.
- **1+ CRITICAL deficiency:** Procedure was fundamentally compromised. Suppression motion warranted.
- **3+ deficiencies of any severity:** Cumulative unreliability. Even if no single deficiency is dispositive, the totality supports suppression under Manson/Brathwaite.
