# D&W Issue Code Taxonomy — Full Reference

**34 codes across 3 categories.** This file is the canonical descriptions document. Read by `dw-issue-code-tracker` during INITIALIZE operation.

## Category 1: UNIVERSAL (14 codes)

Apply to ALL criminal cases. Default status on initialization: `Open`.

| Code | Name | Description |
|------|------|-------------|
| U-01 | Charges | Charging document accuracy, lesser-included offenses, enhancements, statute validity, election of charges |
| U-02 | Criminal History | Prior convictions, predicate exposure, 404(b)/Prieur risk, habitual bills, sentencing priors |
| U-03 | Crime Scene | Photography (gaps/angles), evidence collection, processing protocols, contamination, scene control |
| U-04 | Evidence - Physical | Chain of custody, collection protocols, preservation, contamination, spoliation, weight discrepancies |
| U-05 | Evidence - Exculpatory | Brady material, favorable facts, alternative suspects, undisclosed witness benefits, Giglio impeachment |
| U-06 | Evidence - Incriminating | Damaging statements, forensic hits, DNA inclusion, fingerprint matches, incriminating digital evidence |
| U-07 | Witnesses/Credibility | Witness statements, inconsistencies, bias, motive to lie, impeachment opportunities, prior inconsistent statements |
| U-08 | Eyewitness Identification | Photo array/lineup procedure, cross-racial ID, weapon focus, suggestiveness, Manson/Henderson factors |
| U-09 | Interrogation/Statements | Miranda warnings, custodial coercion, false confession risk, voluntariness, Reid Technique, invocation |
| U-10 | Expert Testimony/Forensic | Expert qualifications, methodology, Daubert/Foret reliability, junk science, basis for opinion |
| U-11 | Timeline/Alibi | Chronology conflicts, alibi corroboration, temporal inconsistencies, gaps, sequence of events |
| U-12 | Electronic Communication | Texts, emails, social media, phone records, dating apps, app data, timestamps, authentication |
| U-13 | Deficient Investigation | Tunnel vision, alternative suspects overlooked, alternative theories not pursued, follow-up gaps |
| U-14 | Search & Seizure / 4th Amendment | Warrants, warrantless searches, consent searches, Terry stops, vehicle searches, phone search scope, Franks issues |
