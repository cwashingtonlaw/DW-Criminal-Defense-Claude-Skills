# ASSET — Preservation Log (Step 5.5)

Appended to every cross-examination outline as the final section. Blank, with Chapter and Question # pre-filled for every flagged question so the attorney is not composing a table mid-cross.

| Chapter | Question # | Ruling | Ground stated | Proffer made | Form of proffer | Issue code |
|---|---|---|---|---|---|---|
| | | Sustained / Overruled | | Yes / No | Q&A / statement / document | |

**Filled in during trial, not before.**

**After trial:** any sustained objection with no proffer is marked **UNPRESERVED** so the attorney can decide whether to revisit before the State rests. The completed log hands off to `dw-appellate-error-monitor-crim` (harmless-error pre-assessment) and `dw-issue-code-tracker-crim`.

**Preservation bullet format** — appears in the NOTES column of every flagged question:

> • **IF EXCLUDED — PRESERVE:** State grounds: [specific ground]. Proffer substance: [one sentence on what the witness would have testified or the exhibit shown]. Request the proffer be taken outside the jury's presence. La. C.Cr.P. art. 841; La. C.E. art. 103(A)(2).

Never write "object and preserve." Name the ground and name the substance — an attorney reading mid-cross has no time to compose either. Grounds by flag type: `references/error-preservation-protocol.md` §3.
