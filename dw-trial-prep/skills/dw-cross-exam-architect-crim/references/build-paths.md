# Build Paths — Full Build vs. Fast Path

**Applied at Step 0.52.** Ask the attorney which path this is, or infer from the request and state the assumption.

---

## The two paths

**FULL BUILD** — the default. Use when preparing a case for trial, when the request names more than one witness, or when no prior cross work exists in this matter.

Runs: `0.55 → 0.58 → 0.6 → 1 → 1.A → 2 → 3 → 4 → 5 → 5.5 → 6 → 8.5`

**FAST PATH** — use when the attorney names **one witness** and needs the outline soon: "cross for Officer [X] tomorrow," "I'm up in the morning," "just the one witness."

Runs: `0.55 → 0.58 → 1 → 2 → 3 → 4 → 5 → 5.5 → 6`

---

## What Fast Path changes

| Step | Full Build | Fast Path |
|---|---|---|
| **0.6** Witness Prioritization Audit (top 10 prosecution witnesses) | Required | **Skipped.** Run the four impeachment categories against **this witness only**, inline, as part of Step 1 — including the art. 608(B) admissibility gate |
| **1.A** Master Witness Table (all witnesses) | Required | **Deferred, not waived.** Add a single row for this witness if a table exists; if none exists, record it as outstanding |
| **8.5** Red-team self-check | Recommended | Optional — note in the Fast Path notice that the outline is untested |

## What Fast Path never skips

Jurisdiction resolution (0.55) · upstream intake and witness history (0.58) · the art. 608(B) admissibility gate · pre-draft confirmation (2) · the Source Register and `(N)` citation discipline (4) · preservation bullets and the Preservation Log (4, 5.5) · the Discovery Gap Report (6).

Those are the parts that keep a cross from failing in the room. Speed comes from narrowing scope to one witness, never from lowering the floor.

The art. 608(B) gate lives in §3.5 of `jurisdiction-and-court-map.md`, loaded at Step 0.5 — so it is in scope on both paths and does not depend on Step 0.6.

---

## Fast Path notice — required on the cover page

Every Fast Path outline carries this line directly under the case caption:

Use the exact text in `assets/fast-path-notice.md` — that file is the single source for it.

State the chosen path in the Step 2 confirmation block. If the attorney later asks for a full build, run 0.6, 1.A, and 8.5, then remove the notice.
