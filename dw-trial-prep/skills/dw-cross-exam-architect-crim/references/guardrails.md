# Guardrails

Loaded at Step 0.5 and in force for the entire build. One line each; the named reference is authoritative for the underlying rule.

**Legal**
- **Name which Fifth Circuit.** `5th Cir.` (U.S. — the firm's correct federal default) vs. `La. 5th Cir.` Never a bare "5th Circuit." Resolve the parish's own Louisiana circuit for state appeals. → `jurisdiction-and-court-map.md` §1
- **Scope is wide open in state court** (art. 611(B)). `[SCOPE FLAG]` only in federal court, on a specific ruling, or on an independently barred area. → `jurisdiction-and-court-map.md` §2
- **Art. 608(B) bars specific-acts character attacks.** Four lawful routes: conviction (**609.1**), bias/interest/corruption (**607(D)(1)**, extrinsic permitted), accuracy of this testimony (**607(C)**), prior inconsistent statement (**613**). Otherwise `[608(B) REVIEW REQUIRED]`. → `jurisdiction-and-court-map.md` §3.5
- **Prior convictions are art. 609.1, never 609.** → `jurisdiction-and-court-map.md` §3
- **Cooperators are a bias case, not a character case.** → `witness-type-modules.md`
- **Surrogate analysts are an objection before a cross.** → `confrontation-and-surrogate-analysts.md`
- **Preserve every flag** — ground stated at the moment (art. 841) plus substance proffered (art. 103(A)(2)). → `error-preservation-protocol.md`
- **Verify statutes.** Louisiana amends frequently; unverified text is marked `[UNVERIFIED — confirm current text]`. → `quick-reference-tables.md`
- **Never coach perjury.** If a question could only be answered truthfully by committing perjury, flag it and drop it.

**Sourcing**
- **Cite every fact** with an `(N)` prefix. **Source numbering is sacred** — a number never changes. → `source-register-and-template.md`
- **No short names.** One name per document, everywhere. The Source Register is three columns — Source Number | Evidence Item | Reference/Bates — with no date column; a date that distinguishes one version from another goes inside the Evidence Item entry. → `source-register-and-template.md`
- **No invented agencies, labs, local practice, or documents.** Unsourced becomes `[UNSOURCED — VERIFY BEFORE USING AT TRIAL]`. → `agency-and-lab-module.md`

**Process**
- **File intake hard stop** before analyzing uploads. **Attorney confirmation** before drafting.
- **Two columns in the chapter table — SOURCE/EXHIBIT (blue) and QUESTIONS (red), both bulleted or numbered, no third column.** Chapter closes with the blank yellow-banded NOTES box. **All three branches still worked on every impeachment question — reported at Step 5, not printed on the page.**
- **One deliverable** — the outline .docx. No Source Catalog, no Combined Sources PDF. The Source Register is the only index, so every register row must be pullable from the case file on its own.
- **Nothing but sources and questions on a chapter page.** Branches, flags and preservation grounds are reported to the attorney and pre-filled into the Preservation Log — and the delivery message says so.
- **Formatting is fixed** — Times New Roman 12 pt, blue `D6E4F0` / red `F4CCCC` / yellow `FFF2CC` header bands, page numbers bottom right, one output folder. → `deliverable-formatting.md`

## How to use these

- The **Legal** rules prevent a wrong or improper question reaching the outline. Check any credibility or impeachment chapter against them before it ships.
- The **Sourcing** rules prevent an outline the attorney cannot stand behind at counsel table.
- The **Process** rules prevent a deliverable that is structurally wrong even where the content is right.
- When a guardrail and a step instruction appear to conflict, the guardrail wins — and say so to the attorney rather than resolving it silently.
