# Module E — Canvass Assignment Builder

Generate structured canvass assignments for field investigators.

## Canvass Design Principles

1. **Start at the scene and work outward** — Begin with immediately adjacent addresses and expand concentrically
2. **Cover all approach and departure routes** — Canvass along every plausible path to and from the scene
3. **Time-match when possible** — Conduct canvass at the same time of day/week as the alleged offense to find recurring witnesses (regular commuters, dog walkers, shift workers)
4. **Document negatives** — Record every address visited, including those where no one answered or no one had information (negative results are still results)
5. **Return visits** — Plan at least two return visits to addresses where no contact was made

## Canvass Assignment Sheet Format

```
CANVASS ASSIGNMENT

Case: State v. [Defendant]          Case No.: [Number]
Date of Offense: [Date]             Time of Offense: [Time]
Canvass Date: [Date]                Canvass Time: [Time]
Investigator: [Name]                License No.: [Number]
Canvass Area: [Description / Map Reference]

ASSIGNMENT ZONE: [Zone designation — e.g., "Zone A: 100-200 Block of Main Street, North Side"]

ADDRESS LIST:
| # | Address | Apt/Unit | Contact Made (Y/N) | Contact Name | Phone | Willing to Talk (Y/N) | Has Info (Y/N) | Statement Taken (Y/N) | Notes |
|---|---------|----------|---------------------|--------------|-------|-----------------------|----------------|-----------------------|-------|
| 1 |         |          |                     |              |       |                       |                |                       |       |
| 2 |         |          |                     |              |       |                       |                |                       |       |

STANDARD CANVASS QUESTIONS:
1. Were you at this address on [date of offense] at approximately [time]?
2. Did you see or hear anything unusual on that date around that time?
3. Do you have any surveillance cameras or doorbell cameras at this address?
4. If yes, was the system recording on [date]? Is the footage still available?
5. Do you know any of the following individuals? [Show photos if authorized by attorney]
6. Have any police officers or investigators visited you about this incident?
7. Is there anyone else at this address who might have information?
8. Are there any regular visitors, delivery drivers, or service workers who frequent this area around [time of offense]?
9. Is there anything else you think might be relevant?

FOLLOW-UP PROTOCOL:
- If witness has relevant information: Take detailed statement, obtain contact info, ask about willingness to testify
- If witness has surveillance footage: Request immediate preservation, arrange to obtain copy ASAP
- If no contact made: Leave business card with brief note (DO NOT describe case details), log for return visit
- If witness is hostile or refuses: Document refusal, do not press, report to attorney

CANVASS MAP: [Attach map with addresses marked and zones designated]

RETURN VISIT LOG:
| Address | Visit 1 Date/Time | Visit 2 Date/Time | Visit 3 Date/Time | Final Status |
|---------|--------------------|--------------------|--------------------|--------------|
|         |                    |                    |                    |              |
```
