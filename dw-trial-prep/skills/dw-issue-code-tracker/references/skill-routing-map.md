# Issue Code → D&W Skill Routing Map

**Version:** 2.0 (renumbered to match canonical taxonomy)

**This is a REFERENCE map only.** `dw-issue-code-tracker` does NOT auto-invoke these skills. The attorney decides when to run them. This map populates the `Linked Skill` column in the Excel `Issue Codes` sheet so the attorney can see at a glance which D&W skill addresses each code.

## Notes for the Attorney

- A single code may map to multiple skills (e.g., U-11 Electronic Communication → 3 skills depending on the specific issue).
- The skills listed are the *primary* responders. Other skills may also touch the issue (e.g., `dw-cross-exam-architect` ultimately consumes most of these for trial prep).
- This map is not exhaustive — refine over time as the firm's skill ecosystem evolves.

## Renumbering Note (v2.0)
