## Quick Reference -- Discovery Demands for Identification Cases

When identification is at issue, demand the following in discovery:

| Item | Why It Matters |
|------|----------------|
| Complete photo array packet (all photos as presented) | Evaluate lineup composition and suspect standout |
| Photo array procedure form / documentation | Evaluate administration protocol |
| Written instructions given to witness | Evaluate instruction bias |
| Identity and training records of administrator | Evaluate blind administration and competence |
| Video/audio recording of identification procedure | Evaluate suggestiveness, witness behavior, administrator cues |
| Witness's initial description of perpetrator (911 call, initial statement) | Compare description to defendant for Manson Factor 3 |
| Confidence statement (verbatim, with timestamp) | Evaluate Manson Factor 4; detect confidence inflation |
| All prior identification procedures involving this witness | Evaluate commitment effect and cumulative contamination |
| Mugshot viewing records | Evaluate prior exposure to suspect's photograph |
| All witness statements (initial, supplemental, grand jury) | Track description and confidence changes over time |
| Department identification procedure policy | Evaluate compliance with department's own standards |
| Administrator's case notes and reports | Detect pre-/post-identification comments or feedback |
| Body camera footage from responding officers | Evaluate witness's initial description and demeanor |
| Communication between witness and law enforcement between crime and identification | Detect information leakage |
| Any media coverage or social media posts showing suspect's image | Evaluate post-event information exposure |
