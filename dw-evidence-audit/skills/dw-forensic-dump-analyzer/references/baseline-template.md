# Pattern of Life Baseline Template

## Baseline Data Structure

Build a 2-week behavioral baseline from outside the critical window (2–4 weeks before the alleged offense):

```
PATTERN OF LIFE BASELINE — [Phone Owner]
──────────────────────────────────────────────────────────
Period: [range] | Daily Msgs: [N] | Active: [hours] | Calls: [N/day]
Top Contacts: [top 5] | Normal Gaps: [patterns]
──────────────────────────────────────────────────────────
```

## Six Required Fields

1. **Period** — Specific date range of baseline measurement
2. **Daily Msgs** — Average daily message count
3. **Active Hours** — Typical hours of phone activity per day
4. **Calls/Day** — Average number of calls per day
5. **Top Contacts** — Five most frequently contacted people
6. **Normal Gaps** — Patterns of expected activity silence or breaks

## Contextualization Method

After baseline is built, revisit critical window findings:
- Upgrade findings where baseline makes them stronger
- Downgrade findings where baseline weakens them
- Add new findings only visible through baseline comparison
- Update the Prosecution Misinterpretation Watch
