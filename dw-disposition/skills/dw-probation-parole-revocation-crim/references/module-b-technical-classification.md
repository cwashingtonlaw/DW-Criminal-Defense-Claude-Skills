# Module B — Technical vs. Non-Technical Classification

Classification is often the whole ballgame: a **technical** violation triggers a capped custodial sanction followed by return to supervision; a **non-technical** violation exposes the client to full revocation (probation: execution of the entire suspended sentence; parole: service of the remaining sentence). Run this worksheet for every allegation, then classify the case by its *worst surviving* allegation (after Module A knocks out what it can).

## B-1. Classification decision tree (probation — La. C.Cr.P. arts. 899.1/900)

For each allegation, ask in order:

1. **Is it a new criminal act?** If no → **technical** (missed check-ins, curfew, fees when *Bearden*-willful, screens, program attendance...). If yes → step 2.
2. **Is the new act misdemeanor possession of marijuana / THC (or paraphernalia)?** If yes → still **technical** by statutory carve-in.
3. **Does it hit the Art. 900 exclusion list?** Felony arrest/conviction; other controlled-substances (Title 40) offenses; intentional misdemeanor directly affecting the person; firearm/prohibited-weapon possession; protective-order violation; absconding; (discretionary) failure to appear [VERIFY — confirm the current statutory exclusion list verbatim]. If yes → **non-technical**.
4. **Absconding vs. missed contacts:** "absconding" implies deliberately evading supervision with whereabouts unknown — a documented address on file, ongoing employment, or any officer contact undercuts an absconding label. Fight the label; missed appointments are technical.

Parole runs the same logic under R.S. 15:574.7/.9, with one gate first: **cap eligibility** — the parole technical caps do not apply at all if the client is on parole for a crime of violence (La. R.S. 14:2(B)) or a sex offense (La. R.S. 15:541).

**Tier-position audit (where tiers apply):** the client's tier depends on *countable prior technical revocations*. Audit each prior: was it actually a technical *revocation* (not an administrative sanction under Art. 899.1, which is a different track)? Was it on this docket/term? A mis-counted tier can double the cap.

## B-3. Classification leverage

- **Push borderline allegations technical**: misdemeanor marijuana carve-in; absconding-vs.-missed-contact; "arrest" that never became a charge; *Bearden* non-willful non-payment.
- **Administrative-sanction off-ramp:** for a clean technical case where the sentencing court authorized Art. 899.1, propose the administrative track (≤ 10 days per violation, ≤ 60 days/year) instead of a court sanction — often the fastest release path. Requires knowing waiver + admission consequences; brief the client first.
- **State the delta:** every deliverable quantifies the difference — e.g., "classified technical: maximum X days then return to supervision; classified non-technical: exposure to the full Y-year suspended sentence." That delta is the negotiation frame.
- Full-revocation exposure math (what the suspended sentence really means in months, with credits) belongs to Module D; sentencing-mitigation content for the underlying term routes to `dw-sentencing-mitigation-specialist-crim`.
