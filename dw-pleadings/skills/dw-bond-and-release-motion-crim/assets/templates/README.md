# Bond Motion Library — Template Inventory

This folder holds firm template exemplars extracted from prior D&W bond filings. Use them as drafting starts alongside (not instead of) the DEVONthink Template-First search in Step 1 of the SKILL.md.

**Important:** Templates here are real prior firm filings with prior client names, docket numbers, facts, and parishes. When using a template:

1. Strip ALL case-specific content (client name, docket number, parish, judge, facts, dates, amounts).
2. Reset the caption using `dw-shared-protocols-crim/references/filed-pleading-boilerplate.md` for the actual filing parish.
3. Verify every citation — both templates predate or are contemporaneous with the 2017 bail-statute renumbering. See `references/bond-caselaw-citations.md` for the consolidated authority inventory with verification flags.

## When to use which template

- **Routine bond reduction, defendant addresses each Art. 316 factor:** Start from `motion_for_bond_reduction.docx` for the short-form structure (numbered paragraphs per factor), but rewrite every citation to current Art. 316 / 341 numbering before drafting.
- **Prolonged detention, contested bond, constitutional argument:** Use `memorandum_in_support_bond_garrison.docx` as the full memorandum model. The motion itself should remain short-form — the memorandum carries the constitutional weight.
- **PR / ROR motion:** Neither bundled template fits. Use the in-skill ROR Motion Structure (Module E / Step 8) or DEVONthink search.
- **Capital / non-bailable offense:** Neither bundled template fits. Use Module G / Step 10 in this skill.
